# AI Trading System

## Overview

AI Trading System is a professional automated trading platform being built from the ground up.

The goal is to create an intelligent trading system capable of trading:

- Cryptocurrency
- Forex
- Gold
- Stocks

This project focuses on:

- Risk management first
- Data-driven decisions
- AI-assisted analysis
- Extensive backtesting
- Paper trading before live trading
